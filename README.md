# x-loader

X.com（Twitter）のブックマークから画像を自動ダウンロードするツールです。フルサイズ画像をユーザー別に整理してダウンロードし、成功後にブックマークを自動削除します。

## 特徴

- **フルサイズ画像のダウンロード**: オリジナル解像度（`name=orig`）で画像を取得
- **ユーザー別整理**: ダウンロード先をユーザー名ごとに自動分類
- **自動ブックマーク削除**: ダウンロード成功後、自動的にブックマークから削除
- **重複防止**: 処理済みポストを追跡し、重複ダウンロードを回避
- **スマート終了**: ブックマークが尽きた場合も正常に終了

## 必要な環境

- Node.js（v14以上推奨）
- npm

## インストール

```bash
# リポジトリをクローン
git clone https://github.com/weakboson/x-loader.git
cd x-loader

# 依存関係をインストール
npm install
```

## 設定

ルートディレクトリに `config.json` ファイルを作成します：

```json
{
  "download_directory": "./images",
  "post_count": 100,
  "cookie": "auth_token=YOUR_X_AUTH_TOKEN"
}
```

### 設定項目

- **`download_directory`**: 画像の保存先ディレクトリ（ユーザー別サブフォルダが自動作成されます）
- **`post_count`**: 処理する最大ポスト数（画像付きポストのみカウント）
- **`cookie`**: X.comの認証クッキー（`auth_token`が必要）

### 認証クッキーの取得方法

1. ブラウザでX.comにログイン
2. 開発者ツール（F12）を開く
3. Application/ストレージ > Cookies > `https://x.com` を開く
4. `auth_token` の値をコピー
5. `config.json` の `cookie` フィールドに設定

**重要**: `config.json` は `.gitignore` に含まれており、リポジトリにコミットされません。認証情報は安全に管理してください。

## ダウンロードされる画像の構造

```
images/
├── @username1/
│   ├── 1234567890_1.jpg
│   ├── 1234567890_2.jpg
│   └── 1234567891_1.jpg
├── @username2/
│   └── 9876543210_1.jpg
└── @username3/
    ├── 5555555555_1.jpg
    └── 5555555555_2.jpg
```

- ユーザー名ごとにサブディレクトリが作成されます
- ファイル名は `{ポストID}_{画像番号}.jpg` の形式です
- 1つのポストに複数の画像がある場合、連番で保存されます

## 動作の仕組み

1. X.comのブックマークページにアクセス
2. 画像付きポストを検索
3. 各ポストから以下の情報を取得：
   - ポストID
   - ユーザー名
   - 画像URL（オリジナル解像度に変換）
4. ユーザー別ディレクトリに画像を保存
5. ブックマークから削除
6. ページをスクロールして次のポストを読み込み
7. 設定数に達するか、新しい画像付きポストがなくなるまで繰り返し

## 制限事項

- 画像付きポストのみ処理（テキストのみのポストはスキップ）
- 動画は未対応（画像のみダウンロード）
- ヘッドレスモードで動作（ブラウザウィンドウは表示されません）
- 有効なX.com認証クッキーが必要

## トラブルシューティング

### 「ブックマーク削除ボタンが見つかりませんでした」と表示される

認証クッキーが無効または期限切れの可能性があります。新しい `auth_token` を取得して `config.json` を更新してください。

### 画像のダウンロードが失敗する

ネットワーク接続を確認してください。一時的なエラーの場合、処理は継続されます。

### 処理が途中で止まる

新しい画像付きポストが2回連続で見つからない場合、自動的に終了します。これは正常な動作です。
